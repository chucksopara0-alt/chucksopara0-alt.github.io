Privacy Policy

Last updated: 14 November 2026

Chux Automations is a personal automation tool operated by Chukwuma Opara (London, UK). It is used only by its owner.

What data is accessed

With the owner's permission, the app accesses Google Drive, Google Sheets and Google Docs through Google's OAuth system so that n8n workflows can read and write the owner's own files.

How data is used

Data is used only to run the owner's automations. It is not sold, shared with third parties, or used for advertising.

Storage and security

OAuth tokens are stored securely in the owner's n8n instance. No Google user data is stored anywhere else by this app.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.
